Вакансии для старта, без ручного поиска

OmskJobHunter раз в два дня проверяет открытые источники, отсекает неподходящее и присылает новые вакансии в Telegram.

Чего в подборке не будет

  • Продажи и холодные звонки
  • Колл-центры и телемаркетинг
  • Вакансии ниже порога по зарплате
  • То, что уже присылали раньше

Как это работает

  1. Сбор

    Запросы к API SuperJob и открытым данным портала «Работа России» по Омску и удалённой работе.

  2. Отбор

    Опыт работы, зарплата, район города, стоп-слова. Повторы отсекаются по идентификатору вакансии.

  3. Отправка

    Только новые вакансии, раз в 48 часов, в личный чат Telegram. Пустая подборка не приходит.

Источники

Проект работает на официальных каналах: открытом API SuperJob и открытых данных портала «Работа России». Публичные сайты не парсятся, защиты не обходятся.
